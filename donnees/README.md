# Données

`ventes.csv` : 289 commandes synthétiques, une ligne par commande, du 2026-09-07 au 2026-10-04 (4 semaines). UTF-8, séparateur virgule.

Colonnes : `id_commande`, `date_commande`, `jour_semaine`, `produit`, `categorie`, `quantite`, `prix_unitaire`, `canal`, `zone`, `mode_paiement`.
Prix en FCFA. Montant d'une commande : `quantite x prix_unitaire`.

4 catégories (Électronique, Beauté, Mode, Maison), 18 produits, 2 canaux (Web, Boutique), 3 zones (Dakar, Thiès, Saint-Louis).

Valeurs de contrôle : CA total 4 066 000 FCFA, 289 commandes, 522 articles, panier moyen 14 069 FCFA.
