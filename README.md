# DataSprint

Tableau de bord de suivi des ventes d'une petite boutique, réalisé en un sprint Scrum de 5 jours.
Projet de Gestion de Projets Agiles, M1 Big Data Analytics, UN-CHK. Groupe 1.

## Ouvrir le tableau de bord

Depuis la racine du dossier, lancer `python3 -m http.server 8000`, puis ouvrir http://localhost:8000/dashboard/.

## Contenu

| Dossier | Contenu |
|---|---|
| `dashboard/` | Le tableau de bord (HTML, CSS, JavaScript) |
| `donnees/` | Le fichier CSV des ventes |
| `docs/` | Les livrables du sprint (un dossier par livrable), l'énoncé, les [rôles](docs/roles.md) et les [règles d'équipe](docs/regles-equipe.md) |
