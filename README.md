## Où suivre le travail

- Le board, le backlog et le Sprint Backlog sont dans l'onglet **Projects** du dépôt (projet « DataSprint »).
- Chaque user story et chaque tâche est une issue.
- Colonnes du board : À faire, En cours, À valider, Terminé.
